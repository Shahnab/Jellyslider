# Jelly Slider

An interactive jelly slider built with TypeScript and WebGPU using TypeGPU.

## 🚀 Live Demo

Try it online: [https://shahnab.github.io/Jellyslider/](https://shahnab.github.io/Jellyslider/)

## 🛠️ Technologies Used

- TypeScript
- WebGPU
- TypeGPU
- Vite

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js (v18 or higher)
- A browser that supports WebGPU

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Shahnab/Jellyslider.git
cd Jellyslider
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 📦 Build

To build the project for production:

```bash
npm run build
```

## 🚀 Deploy

To deploy to GitHub Pages:

```bash
npm run deploy
```
